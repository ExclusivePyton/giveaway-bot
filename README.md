# 🎁 Telegram Giveaway Bot

Бот для проведения розыгрышей в Telegram-каналах с **обязательной подпиской**.

## Возможности

- Создание розыгрышей прямо в боте
- Обязательная подписка на один или несколько каналов
- Автоматическая проверка подписки при участии
- Случайный выбор победителей
- Автоматическое завершение по таймеру
- Публикация поста с кнопкой «Участвовать» в канал

## 🚀 Как запустить на Bothost.ru

### Шаг 1. Создай бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather)
2. Команда `/newbot`
3. Придумай имя и username
4. Скопируй **токен** (выглядит как `123456:ABC-DEF...`)

### Шаг 2. Залей код на GitHub

1. Зайди на [GitHub](https://github.com) → **New repository**
2. Название, например: `giveaway-bot`
3. Создай репозиторий (можно без README)
4. Загрузи файлы из этого архива:
   - `bot.py`
   - `requirements.txt`
   - `README.md`
   - `.gitignore`

**Или** загрузи ZIP прямо на Bothost (см. ниже).

### Шаг 3. Создай бота на Bothost

1. Зайди на [bothost.ru](https://bothost.ru) и зарегистрируйся / войди
2. Нажми **Создать бота** / **Create bot**
3. Заполни:
   - **Название** — любое (например `Giveaway Bot`)
   - **Платформа** — Telegram
   - **Библиотека** — aiogram (или Python)
   - **Bot Token** — токен от @BotFather
   - **Git URL** — ссылка на твой репозиторий  
     (например `https://github.com/твой_ник/giveaway-bot`)
   - **Ветка** — `main` (или `master`)
   - **Главный файл** — `bot.py` (важно!)
4. Нажми **Создать** / **Deploy**

### Альтернатива: загрузка ZIP без GitHub

1. На Bothost в личном кабинете найди кнопку **«Загрузить из архива»** / **Upload from archive**
2. Загрузи файл `giveaway-bot.zip`
3. Укажи:
   - Токен бота
   - Главный файл: `bot.py`
   - Язык: Python / aiogram
4. Нажми **Задеплоить**

### Шаг 4. Переменные окружения

Bothost обычно сам подставляет токен, который ты указал при создании.

Если нужно вручную:
1. Открой настройки бота
2. Раздел **Environment Variables** / **Переменные окружения**
3. Добавь:
   ```
   BOT_TOKEN = твой_токен_от_BotFather
   ```

### Шаг 5. Добавь бота в канал

1. Открой свой Telegram-канал
2. **Администраторы** → **Добавить администратора**
3. Найди своего бота
4. Дай права:
   - ✅ Публикация сообщений
   - ✅ Редактирование сообщений (желательно)
5. Сохрани

### Шаг 6. Проверь работу

1. Напиши боту `/start`
2. Напиши `/new`
3. Следуй инструкциям:
   - Перешли сообщение из канала **или** отправь `@username` канала
   - Укажи название приза
   - Описание
   - Количество победителей
   - Длительность (например `24` = 24 часа, `3d` = 3 дня)
   - Дополнительные каналы для подписки (или `-` если только основной)

Бот опубликует пост с кнопкой **«Участвовать»**.

---

## ⚠️ Важные моменты

1. **Бот должен быть администратором** во всех каналах, где проводится розыгрыш и на которые требуется подписка (иначе не сможет проверить подписку).
2. Каналы лучше делать **публичными** (с @username) — тогда участникам будет удобно подписываться по кнопке.
3. Время окончания указывается в **UTC**.
4. База данных хранится в файле `giveaways.db` внутри контейнера. При пересоздании контейнера данные могут сброситься. Для постоянного хранения можно позже подключить внешнюю БД.

## 🛠 Локальный запуск (для теста)

```bash
# 1. Создай виртуальное окружение
python -m venv venv
source venv/bin/activate   # Linux/Mac
# или
venv\Scripts\activate      # Windows

# 2. Установи зависимости
pip install -r requirements.txt

# 3. Создай файл .env
echo "BOT_TOKEN=твой_токен" > .env

# 4. Запусти
python bot.py
```

## Поддержка

Если бот не запускается на Bothost:
1. Открой **Логи** в панели Bothost
2. Частые ошибки:
   - `ModuleNotFoundError` → проверь `requirements.txt`
   - `BOT_TOKEN not found` → добавь переменную окружения
   - Ошибка доступа к каналу → бот не добавлен как админ

Удачи с розыгрышами! 🎉
